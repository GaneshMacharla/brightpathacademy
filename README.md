## 🚀 How to Run Locally

Since this is a pure static website:

### Option 1: Direct File Open
Simply double-click `index.html` in your file explorer to open it directly in Google Chrome, Microsoft Edge, Safari, or Firefox.

### Option 2: Local HTTP Server (Recommended)
```bash
# Using Python:
python -m http.server 8080

# Or using Node.js:
npx serve .
```
Then visit: `http://localhost:8080`
